COMP 3104 DevOps is a third-year course in the Computer Programming and Analysis program at George Brown College. It covers how development and operations teams work together to build, test and ship software quickly and reliably.

Topics covered so far include version control with Git and GitHub, branching strategies and pull requests, continuous integration with GitHub Actions and Travis CI, and containers with Docker. Later weeks cover configuration management with Ansible and cloud deployment on AWS and Azure.

The course is hands-on: every week has a class exercise that is pushed to GitHub, and the group assignment simulates a real team workflow with one branch per developer, a protected main branch and a CI pipeline that runs on every push.
